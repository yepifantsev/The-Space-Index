The Space Index

This is a personal project connecting my interests in software engineering and everything-space. Started as a rapid SPA prototype using Node.js and Vite, with GitHub Actions fetching and validating external data before publishing this static, database-free site. I now use it to track satellites and rocket launches and plan astrophotography sessions. It is currently locked to my location, but I may consider making it configurable for other astronomy enjoyers.
